# Bundled datasets: sources and licences

The cleaned files are `packages/core/src/data/real/*.json` (`{ "x": rows, "y": labels or values }`),
generated by `pnpm data-ref` (`tools/data-ref/build.mjs`, opt-in, needs network; the generated files
are committed and neither tests nor the app fetch anything). The app lists the same sources under
Data, Sources (`REAL_META` in `packages/core/src/data/real.ts`).

## Opening other data

Data, Open CSV reads a CSV from a URL (only when you press Fetch; the server must allow cross-site
reads) or from a local file. Limits: 5000 rows, 50 columns, 20 classes, 2 MB. The first row is the
header. Text input columns are left out and rows with a missing value are dropped; both are
reported in the dialog. The opened file lives in the session only: it is not part of a saved model.
